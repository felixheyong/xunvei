调整建议 — 如何达到连续级配合规

基于组合过筛率理论和堆积密度模型，针对当前偏差给出具体的配合比调整方案。

💡 调整原则：
  • 粗端不足 → 增加粗骨料比例，或选用粒径更大的粗骨料
  • 细端超标 → 减少超细砂比例，或选用更粗的砂源（FM 更高）
  • 保持连续级配： 避免某档筛孔出现"断崖"，确保曲线平滑过渡
  • 调整幅度： 每次调整 2–5%，逐步逼近，避免过度修正
  • 钢纤维影响： 钢纤维等效于"超大颗粒"，粗端应略低于 Fuller 曲线

组合过筛率理论 — 颗粒堆积密度模型

组合级配优化的核心目标是最大化骨料堆积密度（最小化空隙率），从而减少水泥浆体需求、降低收缩、提高强度和耐久性。

🎯 组合过筛率公式

混合骨料在筛孔 d 处的累计过筛率由各组分按比例加权求和：

Pcombined(d) = Σ [ pi × Pi(d) ]

其中 pi = 第 i 种骨料的质量比例，Pi(d) = 该骨料在筛孔 d 处的过筛率。

📐 Fuller-Thompson 方程

经典最大密实度理想级配曲线 (1907)：

P(d) = 100 × (d / Dmax)n

n = 0.5（Fuller 原始）或 n = 0.45（FHWA 推荐，最大密实度）。Dmax = 最大骨料粒径 25mm。

🔬 Andreasen-Andersen 模型

连续级配堆积模型 (1930)，引入分布模数 q：

P(d) = 100 × (d / Dmax)q

最优堆积时 q ≈ 0.37（比 Fuller 略细）。适用于包含微粉的连续级配体系。

🧱 可压缩堆积模型 CPM

de Larrard (1999) 提出的现代堆积理论，考虑了：

  • 松散效应：细颗粒撑开粗颗粒骨架
  • 壁效应：粗颗粒表面附近细颗粒无法紧密堆积
  • 压实指数 K：反映施工振捣 / 压实程度

⚙️ Twintec SFRC 工程修正

Twintec 的目标范围是对经典堆积理论的工程修正：

  • 粗端略开（为钢纤维留空间）
  • 细粉严格控制（< 0.15mm 上限 3%）— 防止塑性收缩开裂
  • 中粒径区保持连续级配 — 保证工作性和表面平整度

📊 细度模数 FM

FM = Σ(累计筛余%) / 100，只用标准筛 0.15–4.75mm。

FM = R4.75 + R2.36 + R1.18 + R0.6 + R0.3 + R0.15

混合砂的组合 FM 为各组分的质量加权平均值。地坪推荐 FM 2.5–3.2。
